Full Text: "Choosing the Right Operating System"

🔊 Listen to this article
Choosing the Right Operating System
A guide for new IT students in Taiwan
Name: Wang Junwei (王俊偉) Age: 22 Job: IT Support Intern
Company: A computer repair shop, Taoyuan Education: Third-year Information Management student

Background — Why OS Choice Matters

Junwei works part-time at a computer repair shop. Every day, customers bring in computers with different operating systems. He says, 'Understanding operating systems is essential for any IT professional. Each OS has its own strengths and weaknesses.'

Windows — The Most Popular Choice

Windows is the most common operating system in the world. There are many versions: Windows 10, Windows 11. Most office computers use Windows because there are many compatible programs. Junwei says, 'Windows is familiar to most users, but it can be slow if the computer has old hardware.'

macOS — The Creative Professional's Choice

macOS runs on Apple computers. It is popular with designers, video editors, and musicians. There are fewer viruses for macOS. The interface is clean and easy to use. However, Apple computers are expensive. Junwei notes, 'There aren't many games for macOS, but for creative work, it's excellent.'

Linux — The Open Source Option

Linux is free and open source. There are many versions (distributions) like Ubuntu, Fedora, and Debian. Linux is popular with programmers and server administrators. It is very secure and customizable. Junwei is learning Linux for his IT career. 'There isn't a graphical interface as polished as Windows or macOS, but the command line is powerful.'

"The best operating system is the one that fits your needs. Don't follow trends — understand what you need to do, and choose accordingly." — — Wang Junwei, IT Support Intern

Quick Review: What Are Imperatives?

Imperatives are commands or instructions. They are the base form of the verb with no subject.

PatternExample
Positive imperativeClick the Start button.
Negative imperativeDon't touch the screen.
Polite imperativePlease restart your computer.
Let's + verbLet's check the settings.
Key Rules
  • Use imperatives for clear instructions: Open the Control Panel. Click Network Settings.
  • Add 'please' for politeness: Please save your work before shutting down.
  • Negative: Don't + base form: Don't delete system files.
  • For step-by-step instructions, use numbered imperatives: 1. Click Start. 2. Select Settings. 3. Choose Network.
Common Mistakes (Chinese L1 Speakers)

Chinese speakers: Don't add 'to' before the verb. ✗ Please to click the button. → ✓ Please click the button.
